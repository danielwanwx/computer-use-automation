# Safe evidence

`index.json` is the release-safe evidence index. It records a Codex saved-login lifecycle diagnostic, the current-source V2 native loopback replay with an injected offline scripted backend, and a partial V11 clean-checkout diagnostic. The Codex record is intentionally `PARTIAL_DIAGNOSTIC`: its value-safe capability was approved only in a temporary registry and has no committed approval sidecar, so the verifier keeps V1 `NOT_RUN`. V11 remains `NOT_RUN` until native no-model replay runs from a clean checkout with an approved real artifact. The index does not claim a release-qualified live artifact or real-person takeover. Runtime evidence is written beneath the configured local evidence root as typed metadata, JSONL safe events, and value-free structural snapshots. Private/generated evidence belongs under `evidence/private/`, which is ignored.

Do not copy credentials, account IDs, balances, goals, raw DOM, URLs with query values, tokens, HAR files, videos, or model payloads into this directory. A future verified entry must identify whether evidence came from the native target or an injected test harness.
