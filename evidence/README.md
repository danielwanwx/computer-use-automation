# Evidence

Start with **[RUN_LOG.md](RUN_LOG.md)**, a readable rendering of everything below. It is regenerated by `scripts/render_evidence_log.py`.

| Path | What it is | Produced by |
|---|---|---|
| `live_lifecycle.json` | Summary of the live run: provider/model, trace, artifact digest, validation, approval, replay counts, and the six error/outcome replays | `CUA_LIVE=1 scripts/discover_and_replay.py` |
| `live_run/discovery_decisions.json` | Every model call during discovery: the value-free request the model saw (route, page state, offered controls, signals, recent history) and its typed decision with rationale and token usage | same |
| `live_run/record_*.json` | One record per run (discovery, validation, 10 replays, 6 error/outcome replays): run metadata, ordered safe events, structural page snapshots. `index.json` lists them with SHA-256 digests | same, via `scripts/export_safe_evidence.py` |
| `handoff_run/handoff_summary.json` | Replay blocked by an unexpected dialog, then handed to an operator on the same page: intervention request, state timeline (owner/epoch), the operator's action, final result | `scripts/demo_handoff.py --export` |
| `handoff_run/record_*.json` | Safe event record of that replay | same |
| `handoff_person_rehearsal.json` | Structural record of an earlier handoff in which a person operated the headed browser | earlier revision (see its `note`) |

## What is deliberately absent

Account numbers, balances, customer names, credentials, tokens, URLs with query values, page text, raw DOM, screenshots, and full model payloads are never recorded. Runs are identified by random aliases. Snapshots record only structure: route, page state, and control roles and counts. Every exported file was scanned for all synthetic values of its run, and the export fails on any match. Each record carries the source fingerprint of the code that produced it and the artifact digest it replayed.

The synthetic customers are created with random passwords at the start of each run and exist only in the local ParaBank database.
